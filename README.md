Optix – AI-Powered Visual Assistant

Optix is an intelligent visual search application that combines Computer Vision and Agentic AI to help users understand and interact with the world around them. Users can capture or upload images to identify objects, extract text, translate content, and receive contextual explanations through a conversational AI assistant. Unlike traditional image recognition tools, Optix not only recognizes what is in an image but also answers follow-up questions, providing a more interactive and informative experience.

Features

📷 Real-time object recognition

📝 Text extraction (OCR) from images

🌐 Multi-language text translation

🤖 AI-powered explanations and follow-up Q&A

📚 Educational assistance for notes, diagrams, and everyday objects

🔍 Visual search and contextual information retrieval

⚡ Fast, intuitive, and user-friendly interface


How It Works

1. The user captures or uploads an image.


2. Computer vision models analyze the image and detect relevant information.


3. The AI agent interprets the results and generates meaningful insights.


4. Users can ask additional questions to gain deeper understanding of the identified content.



Technologies Used

Frontend: React Native (Expo)

Language: TypeScript

Camera Integration: Expo Camera

AI & Vision: Gemini API / Gemini Vision

State Management: React Hooks / Context API

Backend : Node.js & Express

Database :  Supabase



Vision

Optix aims to bridge the gap between the physical and digital worlds by transforming visual information into actionable knowledge. By leveraging the power of AI, it enables users to learn, discover, and explore their surroundings in a smarter and more interactive way.
